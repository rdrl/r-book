# 背包十年：我的职业是旅行

> 走过越多的路，越明白世界不是由坐标构成的，而是由一次次出发与重逢构成的。

## 第一章 出发：从一张单程票开始

十年前第一次背起65升的登山包时，我并不知道这段旅程会持续整整十年。那时候行囊里塞满了不必要的指南针、厚重的词典和多余的衣物，却唯独缺少面对未知的从容。

### 1.1 青年旅舍里的世界地图

在清迈老城的一家木结构青旅里，墙上贴满了来自世界各地旅行者留下的便签。有人用铅笔写下穿越陆路边境的路线，有人画下自己在安纳普尔纳大环线看到的星空。

- **极简行囊法则**：凡是三天内没有用到的物品，大概率整趟旅途都不需要。
- **慢速移动**：与其在十天内打卡八座城市，不如在一个清晨跟着当地人去一次菜市场。

## 第二章 跨越山海的独行时刻

当火车穿过西伯利亚无边的白桦林，窗外的风景在数日之内几乎保持着同样的节奏。正是在这种漫长的空白里，阅读与记录成为了旅途中最忠实的陪伴。

```text
路线记录：北京 -> 二连浩特 -> 乌兰巴托 -> 伊尔库茨克（贝加尔湖） -> 莫斯科
历时：19天 | 方式：国际列车 + 徒步
```

## 第三章 归来仍是出发者

真正的旅行从来不是为了逃离生活，而是为了在看过足够辽阔的坐标系之后，依然热爱眼前的每一顿早餐与每一本好书。
