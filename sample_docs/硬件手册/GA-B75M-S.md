# GA-B75M-S 主板硬件维护与技术手册

本手册提供 **GA-B75M-S (Rev 1.0)** 主板的核心规格参数、跳线定义、存储接口说明及常见故障排查流程。

## 1. 核心硬件规格总览

| 模块名称 | 规格参数说明 |
| :--- | :--- |
| **处理器接口** | 支持 LGA1155 封装 Intel 第 2 代 / 第 3 代 Core i7 / i5 / i3 / Pentium / Celeron 处理器 |
| **芯片组** | Intel B75 高速芯片组 |
| **内存支持** | 2 x DDR3 DIMM 插槽，最高支持 16 GB 双通道 DDR3 1600/1333/1066 MHz |
| **存储接口** | 1 x SATA 6Gb/s (SATA3_0 原生高速口) + 3 x SATA 3Gb/s (SATA2_1~3) |
| **扩展插槽** | 1 x PCI Express x16 (支持 PCIe 3.0) + 1 x PCI Express x1 |
| **板载网卡** | Realtek GbE 千兆以太网控制芯片 (10/100/1000 Mbit) |

## 2. 关键接口与装机布线指南

### 2.1 SATA 接口速率区分

装机接入固态硬盘（SSD）时，请务必将系统盘连接至白色 **`SATA3_0`** 接口，以获得完整的 6Gb/s 持续读写带宽；机械硬盘（HDD）可连接至其余黑色 `SATA2` 接口。

### 2.2 前置面板跳线 (`F_PANEL`) 定义

```text
  +PWR_LED-   +PWR_BTN-
  [ 1 ][ 3 ]  [ 5 ][ 7 ]
  [ 2 ][ 4 ]  [ 6 ][ 8 ]  [ 10 (NC) ]
  +HDD_LED-   +RESET-
```

## 3. BIOS 重置与常见故障诊断

1. **开机无显示 / 内存自检未通过**：请先断开 220V 电源线，拔下内存条使用橡皮擦拭金手指，优先单条插入 `DDR3_1` 插槽测试。
2. **清除 CMOS 参数 (`CLR_CMOS`)**：在断电状态下，使用金属镊子短接主板右下角 `CLR_CMOS` 两针跳线 5 秒，或取下 CR2032 纽扣电池静置 1 分钟即可恢复出厂设置。
